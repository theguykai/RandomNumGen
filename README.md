# This project was to assist an activation for the Supercars at Bathurst

I used React (create-react-app, I still hadn't learnt a framework at this time), TailwindCSS, ExpressJS and Socket.io for the tech stack.

The app itself is designed to display a promotional video for the meat tray giveaways at the Repco Bathurst 1000 Supercars event.

The promotional video plays on a screen facing the audience, and the host has a display of a range of numbers he can enter, and then hit generate to generate a random number.

When the number is generating, it jumps through a bunch of random numbers on the screen the crowd can see, and a text-to-speech voice announces the number.
